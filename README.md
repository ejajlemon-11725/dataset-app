Dataset App

A Final Year Design Project developed as a dataset-focused application.
This repository contains the complete source code for the web application and its Android/Capacitor project.

📌 Project Overview

Dataset App is designed as an application for working with dataset-related information in a simple and organized way. The project was developed as part of a Final Year Design Project with the goal of providing a practical, user-friendly platform for dataset-based tasks.

The project includes a web interface and an Android application structure generated using Capacitor.

🚀 Main Technologies

HTML — Web page structure

CSS — User interface styling

JavaScript — Application functionality

Capacitor — Android application integration

Android Studio / Gradle — Android project and build system

Git & GitHub — Version control and project management

🛠️ Installation and Setup

1. Clone the repository

git clone https://github.com/ejajlemon-11725/dataset-app.git

2. Open the project

cd dataset-app

3. Install dependencies

npm install

4. Run the web project

The web files are available inside the www/ directory.

You can open:

www/index.html

in a browser for the web interface.

📱 Android Application

This project uses Capacitor for Android integration.

To open the Android project in Android Studio:

npx cap open android

To synchronize web changes with the Android project:

npx cap sync android
